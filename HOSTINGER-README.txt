HOSTINGER DEPLOYMENT - STATIC VERSION
====================================

This package is the pre-built static version of PrimeRiseTech and does NOT require Node.js.

IMPORTANT:
1. Upload/copy the CONTENTS of this folder into Hostinger's document root (normally public_html),
   not the folder itself.
2. The document root must contain index.html directly.
3. If using Hostinger Git deployment, connect the repository/branch whose ROOT contains index.html,
   assets/, about/, services/, contact/, get-started/, and .htaccess.
4. Do not point Hostinger's document root at the React/TanStack source folder.
5. Clear Hostinger cache after deployment if an old 403 is still displayed.

The site is static and therefore works on Hostinger plans without Node.js hosting.
